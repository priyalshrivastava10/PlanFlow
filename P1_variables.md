# Variables in the P1 user template

| Variable | What it holds | Example |
|---|---|---|
| {subjects_with_difficulty} | Subject names with difficulty (Hard / Medium / Easy) | Mathematics (Hard), Python (Easy) |
| {exam_dates} | Exam date for each subject | Mathematics 28 Nov, Python 4 Dec |
| {start_date} | First day of the plan | 23 Nov |
| {daily_hours} | Maximum study hours per day (number) | 4 |
| {preferred_time} | Time window the student prefers | 6 PM to 11 PM |
| {break_rule} | How often and how long breaks are | 10 minutes after every hour |
